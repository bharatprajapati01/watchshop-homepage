# WatchShop Clone

A responsive WatchShop homepage clone built using **HTML, CSS, and Tailwind CSS**.

## Features

* Responsive homepage design
* Navigation bar
* Watch product sections
* Modern UI design
* Responsive layout for different screen sizes
* Built with HTML, CSS, and Tailwind CSS

## Technologies Used

* HTML5
* CSS3
* Tailwind CSS

## Project Purpose

This project was created for learning and practicing frontend web development, responsive design, and Tailwind CSS.
